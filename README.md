## ⚡ Highlights

- **Zero Timeline Editing**: Drop in an `.html` animation or `.md` presentation slide deck and preview it instantly.
- **Studio-Grade MP4**: Export 1080p 60 FPS videos with real-time multi-aspect ratio switching (`16:9 Cinema`, `9:16 Reel`, `1:1 Square`).
- **Dual-Engine Architecture**: Hardware GPU acceleration (Direct3D11) when running locally, and 100% in-browser WebCodecs when deployed online.
- **Built-in Vault**: Review, download, or delete past renders with persistent history tracking.

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/msajiddurrani/RenderFlow.git
cd RenderFlow

# Install dependencies
npm install

# Start local studio
npm start
```

Open **[http://localhost:3333](http://localhost:3333)** in your browser.

---

## 🌐 Deploy to Vercel

RenderFlow is ready for 1-click deployment on **Vercel** with client-side WebCodecs rendering:

1. Import this repository into your Vercel account.
2. Vercel automatically detects `vercel.json` and deploys the static application with zero server configuration.
